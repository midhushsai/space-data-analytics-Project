## Problem
Estimate the redshift (z) of galaxies using photometric features from tabular data.

## Approach
- Load dataset containing galaxy features
- Separate input features and target variable (redshift)
- Split data into training and testing sets
- Train a machine learning model (Random Forest)
- Evaluate model using Mean Absolute Error (MAE)
