# Q1: Meteor Detection

## Problem
Detect meteor events from antenna signal data. A meteor appears as a sudden spike (peak) in the signal compared to surrounding values.

## Approach
- Load signal data from CSV file
- Visualize signal using matplotlib
- Detect peaks using scipy's 
- Apply threshold to filter significant spikes
- Count total peaks (meteor events)

## Tools Used
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
